## System requirements
- STM32F411 MCU
- Battery powered
- USB debugging/programming
- MicroSD data logging
- GPS positioning
- 9-axis IMU
- Pressure/temperature sensor
- Status LEDs
- Small size
- I2C interface
- UART interface for GPS module
- SPI interface for SD

## Hardware components
- STM32F411CEU6
- BNO085
- BME280
- MicroSD socket
- USB-C connector
- Battery connector
- LDO regulator
- Power LED
- Status LED
- SWD header
- Boot/Reset buttons
