## System requirements
- STM32F411 MCU
- Battery powered
- USB debugging/programming
- MicroSD data logging
- GPS positioning
- 9-axis IMU
- Pressure/temperature sensor
- Status LEDs
- Small size
- I2C interface
- UART interface for GPS module
- SPI interface for SD

## Hardware components
- USB-C connector
- Battery connector
- LDO voltage regulator
- Power LED
- Status LED
- Serial Wire Debug (SWD) header for STM32
- Boot/Reset buttons
- Decupling Capacitors
- ADC (STM32 has one built in?)

Resistors
-LED current limiting resistor
-I2C pull-up resistors
-USB resistors (if USB-C)
-BOOT resistor
-RESET pull-up
-Battery divider
